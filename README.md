# Nexus Pay – Digital Payments & Transactions Coordination Platform

##  Problem Statement

Nexus Pay is a digital payments and transactions coordination platform designed to provide a secure, reliable, and centralized system for managing payments between customers, merchants, and banks. The platform aims to simplify digital payment processing, improve transaction transparency, and offer real-time access to balances, reports, and payment status for all stakeholders. It also enables administrative control and analytics to ensure smooth operations and issue resolution.

## Identified Actors

1. Merchant  
2. Customer  
3. Bank Admin  
4. Nexus Pay Admin  



## Planned Features for each Actor

### Merchant

- Receive payments from customers  
- Check current account balance  
- View transaction history  
- Generate financial year reports  


### Customer

- Make and Receive digital payments  
- Check account or wallet balance  
- View transaction history
- Make Scheduled Payments
- preferences (changing language, theme,blocked contacts ,notifications )
- split payment
- core profile features 


### Bank Admin

- View and manage payment status  
- Monitor transaction processing between bank systems and Nexus Pay  



### Nexus Pay Admin

- View all platform transactions  
- Access analytics and insights (transaction trends, volume, success/failure rates)  
- Contact and manage support requests  
- Monitor overall platform operations
- role based access control
